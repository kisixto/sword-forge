# sword-forge — 검 강화 대장간

골드로 검을 강화하는 브라우저 게임입니다. 설치 없이 `index.html` 하나로 동작합니다.

## 플레이

`index.html`을 브라우저로 열면 바로 시작됩니다. GitHub Pages를 켜면(Settings → Pages → Branch: `main`) 링크로도 플레이할 수 있습니다.

## 규칙

**일반 검**
- +0에서 시작해 +20까지 강화합니다. 레벨이 오를수록 성공 확률은 낮아지고(+0 99% → +19 46%) 강화 비용은 올라갑니다(100 G → 약 2만 2천 G).
- 강화에 실패하면 검이 부서지고 새 +0 검을 받습니다.
- 검은 레벨이 높을수록 비싸게 팔 수 있습니다. 어디서 멈추고 팔지 정하는 것이 핵심입니다.

**금검**
- 일반 검이 +20에 도달하면 금검으로 진화하고, 금 +0부터 금 +20까지 강화합니다. 일반 +20은 팔 수 없습니다.
- 금검이 된 뒤에는 팔거나 부서져도 새 금검(금 +0)에서 다시 시작합니다. 일반 검으로는 돌아가지 않습니다. 금 +0은 공짜로 받는 검이라 팔 수 없습니다.
- 성공 확률은 일반 검의 60%입니다(금 +0 59% → 금 +19 28%). 금 +10까지 한 번에 갈 확률은 약 0.3%입니다.
- 강화 비용은 2만 G에서 레벨마다 1.2배입니다(금 +19에서 63만 9천 G). 판매가는 금 +1이 4만 1,600 G에서 시작해 레벨마다 1.6배이며, 금 +10은 286만 G, 금 +20은 3억 1,400만 G입니다. 기대값으로는 금 +1에서 파는 것만 이득이고 그 위는 도박입니다.
- 골드가 바닥나 강화도 판매도 못 하면 금 +0 강화 3회분(6만 G)까지 지원금이 채워집니다.

**상점**
- 행운의 가루(성공 확률 +10%p), 할인 쿠폰(비용 50%), 수호 부적(파괴 1회 방어), 대장간 화로(영구 +1%p, 최대 10단계), 자동 망치(목표 레벨까지 자동 강화).
- 금검이 된 뒤에는 모든 가격이 1.5배가 되고, 소모품(가루, 쿠폰, 부적)은 8배가 더해집니다.

**기타**
- 성공·파괴 이펙트와 효과음이 있고, 상단 버튼으로 각각 끌 수 있습니다.
- 진행 상황은 브라우저의 localStorage에 저장됩니다.

## 밸런스 표

`sword-forge-balance.xlsx`에 확률, 강화 비용, 판매가, 한 번에 도달할 확률, 상점 가격이 수식으로 정리되어 있습니다. 이 표는 금검 개편 전 기준이라 일반 검 구간(+0~+19) 외에는 현재 게임과 다릅니다. 게임 코드의 값은 `index.html`의 `baseRate`, `baseCost`, `sellPrice`, `goldRate`, `goldSell`, `goldCost`에 있습니다.
