# sword-forge — 검 강화 대장간

골드로 검을 강화하는 브라우저 게임입니다. 설치 없이 `index.html` 하나로 동작합니다.

## 플레이

`index.html`을 브라우저로 열면 바로 시작됩니다. GitHub Pages를 켜면(Settings → Pages → Branch: `main`) 링크로도 플레이할 수 있습니다.

## 규칙

- 검은 +0에서 시작해 최대 +20까지 강화합니다. 레벨이 오를수록 성공 확률은 낮아지고(+0 99% → +19 46%) 강화 비용은 올라갑니다(100 G → 약 2만 2천 G).
- 강화에 실패하면 검이 부서지고 새 +0 검을 받습니다.
- 검은 레벨이 높을수록 비싸게 팔 수 있습니다. 어디서 멈추고 팔지 정하는 것이 핵심입니다.
- +20에 도달하면 검이 금 검으로 바뀌고 판매가가 2배가 됩니다. 금 검을 처음 완성한 뒤로는 상점 가격이 영구적으로 1.5배가 됩니다.
- 상점 아이템: 행운의 가루(성공 확률 +10%p), 할인 쿠폰(비용 50%), 수호 부적(파괴 1회 방어), 대장간 화로(영구 +1%p, 최대 10단계), 자동 망치(목표 레벨까지 자동 강화).
- 성공·파괴 이펙트와 효과음이 있고, 효과음은 우측 상단 버튼으로 끌 수 있습니다.
- 진행 상황은 브라우저의 localStorage에 저장됩니다.

## 밸런스 표

`sword-forge-balance.xlsx`에 확률, 강화 비용, 판매가, 한 번에 도달할 확률, 상점 가격이 수식으로 정리되어 있습니다. `가정` 시트의 파란 글씨 값을 바꾸면 모든 시트가 다시 계산됩니다. 게임 코드의 값은 `index.html`의 `baseRate`, `baseCost`, `sellPrice`에 있습니다.
